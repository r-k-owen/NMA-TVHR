# NMA-TVHR 
Pairwise (PWMA) and network meta-analysis (NMA) of time to event outcomes assuming non-proportional hazards using a time varying hazard ratio approach.

# Example Data 
Pairwise MA: https://search.r-project.org/CRAN/refmans/surrosurv/html/gastadv.html 

Network meta-analysis: melanoma_ipd.csv

# Pairwise meta-analysis
## Descriptive analyses
Pairwise meta-analysis: descriptive_pw_RScript.R

## Constant and TVHR
Constant and TVHR: tvhr_pw_RE_RScript.R

# Network meta-analysis 
## Descriptive analyses
Network meta-analysis: descriptive_nma_RScript.R

## Constant HR  
Fixed effect model: ph_nma_FE_RScript.R 

Random effects model: ph_nma_RE_RScript.R

## TVHR
Fixed effect model: tvhr_nma_FE_RScript.R

Random effects model: tvhr_nma_RE_RScript.R
